2. Key Local REST Endpoints

  • GET /api/status — Health check (returns {"ready": true})
  • POST /api/getAllChats — Fetches chat list
  • POST /api/getChatMessages — Fetches messages for a chat
  • POST /api/waitMessages — Long-poll notification for signature changes
  • POST /api/getPinnedChats & POST /api/togglePinChat — Local chat pin persistence
  • POST /api/sendReaction — Add or remove emoji reaction
