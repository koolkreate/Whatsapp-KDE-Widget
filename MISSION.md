# Mission

## Reason for Learning
Master the technology stack powering the WhatsApp KDE Plasma 6 widget to comfortably build, debug, and customize desktop widgets and local backend services.

## Specific Goals
- [ ] Understand the dual-layer architecture: QML (Frontend) + Node.js/Puppeteer (Backend)
- [ ] Learn QML declarative UI layout, state management, and `XMLHttpRequest` integration
- [ ] Learn Node.js backend concepts, Express endpoints, long-polling, and Puppeteer DOM manipulation
- [ ] Gain hands-on experience modifying, extending, and testing the codebase
